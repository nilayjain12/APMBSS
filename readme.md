# MoodSync - Automated Personalized Mood-Based Song Selector Web Application

## Short Description

MoodSync is an end-to-end web application that leverages machine learning to enhance the in-car music experience by automating the song selection process while driving. The application adapts to the driver's mood as well as the current weather conditions, recommending songs that match the detected mood. Utilizing the car's camera, MoodSync detects the driver's facial expressions to gauge their emotions. Additionally, it assesses the current weather to predict a mood and suggest a fitting song accordingly.

## Technology Used

1. **Front-End**: HTML, CSS, JavaScript
2. **Back-End**: Python, Flask
3. **Database**: MongoDB (User Authentication)
4. **REST API**:
    - Open-Meteo Weather API (Weather Detection)
    - Spotify Developer API (Song Suggestion)
    - Media-Pipe API (Using Face Mesh for Face Detection)
5. **ML Technologies**:
    - TensorFlow
    - Scikit-Learn
    - Keras
